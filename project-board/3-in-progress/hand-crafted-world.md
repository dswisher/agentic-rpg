# Hand-Crafted World

Build the authoritative in-memory world model and initial three-room game world.

## Stories

- **Define Room Model** — Add a minimal model for rooms, named exits, and room descriptions.
- **Define Item Model** — Add a minimal model for items and their location in the world or player inventory.
- **Define Player State** — Track the player's current room and inventory in the game session.
- **Create Demo World** — Create three hand-crafted connected rooms and one takeable item.
- **Start In Demo World** — Initialize each new game session in the starting room of the demo world.
